# Дизайн админки

Рабочий инструмент диспетчера, а не витрина: сначала понятность и скорость, бренд — в деталях. Цвета и шрифты
задаются только токенами из `src/styles/index.css`; в компонентах — классы Tailwind на этих токенах.

## Токены

| Роль | Светлая | Тёмная | Где |
| --- | --- | --- | --- |
| `bg` | `#f5f6f8` | `#15181c` | фон страницы |
| `surface` / `surface-2` / `raised` | `#ffffff` / `#eff1f4` / `#ffffff` | `#1b1f24` / `#22272d` / `#2e343c` | карточки, панели / наведение, дорожка табов / активный таб |
| `text` / `muted` | `#1f252c` / `#5c6670` | `#e2e5e9` / `#99a1ab` | основной текст / подписи, контраст ≥ 4.5:1 к bg, surface, surface-2 |

| `accent` | `#2e7a5e` | `#4f9d7e` | главное действие, выбранное, прогресс, знак сервиса |
| `accent-hover` / `accent-soft` / `accent-text` | `#276950` / `#e4f0ea` / `#ffffff` | `#5aa98a` / `#1e2f28` / `#0e1714` | наведение, фон выбранного и выделения, текст на акценте |

Акцент — только на главном действии, выбранном и данных. Не красим им заголовки, рамки и украшения.

## Шрифт

Системный (`system-ui`, Segoe UI на Windows): один шрифт на всё, кириллица есть везде. Флаги стран — шрифт `Twemoji Country Flags` (`public/fonts/`), иначе на Windows вместо флага две буквы. Основной текст 14px
(`text-sm`), подписи 13px (`text-caption`), заголовок карточки 15px (`text-base`), окна 16px (`text-lg`), страницы 18px
(`text-xl`), цифры — `tabular-nums`.

Высота контролов — `h-control` / `min-h-control` 36px и `control-sm` 32px, при `pointer: coarse` обе 44px. Другой высоты у кнопок, полей и select не бывает: e2e `layout` падает вне 32–36px (мышь) и ниже 44px (тач).
Радиусы: `rounded-md` 6px, `rounded-lg` 8px (контролы), `rounded-xl` 10px (карточки), `rounded-2xl` 12px (окна). Поля ввода на тач-экранах 16px
(правило в `index.css`), иначе iOS увеличивает страницу.

## Поверхности

- Карточки: `rounded-xl`, рамка 1px, **без тени**. Тень — только у того, что всплывает: модальные окна, шторки,
  меню, панель выбранных групп.
- Внутри карточки не делаем вторую карточку с рамкой — разделяем линией `border-t` или отступом.
- Цифры состояния — одной полосой (`StatsCards`), не плитками с иконками.
- Статусы — `Badge` с тоном из `shared/ui/tone.ts`.
- Карточка — только компонент `Card` (`shared/ui/card.tsx`, атрибут `data-card`): по нему e2e проверяет, что содержимое не выходит за край.
- Колонки карточек на «Настройках» независимы по высоте: соседняя карточка не растягивается под длинную.
- Длинные списки — страницами через `Pager` (10 / 25 / 50 / 100), а не «показать ещё».

## Сетка и адаптив

| Ширина | Навигация | Списки |
| --- | --- | --- |
| < 768px (`md`) | шапка сверху + нижняя панель разделов | заявки и группы — строки-карточки |
| 768–1023px | боковое меню 224px | заявки — строки-карточки |
| ≥ 1024px (`lg`) | боковое меню | заявки — таблица |

- Колонки сетки — `minmax(0,1fr)`, иначе широкая таблица раздувает страницу на телефоне.
- Таблицы шире экрана не делаем: на узких экранах — отдельная разметка списком.
- Всё фиксированное внизу (уведомления, панель выбранных групп) — выше нижней панели и
  `env(safe-area-inset-bottom)`.
- Проверка: e2e `layout` на 360 / 390 / 768 / 1024 / 1440 px (тёмная тема — 390 и 1440, тач-планшет — 1024): нет горизонтального скролла, ничего не вылезает из карточек, шевроны и иконки на месте, сегменты в одну линию, контраст ≥ 4.5:1. Скриншоты — `e2e-results/layout/`.

## Движение

Только состояние: 150–200 мс (`TRANSITION` в `styles.ts`, `animate-fade-in` / `rise-in` / `slide-in` у всплывающих
слоёв через `motion-safe:`), при `prefers-reduced-motion` всё отключено. Без анимаций появления страниц и секций.

## Знак

`shared/ui/logo.tsx` и `public/favicon.svg` — облачко чата, из которого сообщение расходится по трём группам.
Не заменять буквой в квадрате.

## Не делаем

Градиенты, эмодзи вместо иконок (иконки — только `lucide-react`), мелкие подписи капсом над заголовками,
стрелки «→» в конце кнопок и ссылок, тени на карточках в покое, одинаковые плитки с иконками в кружках.
