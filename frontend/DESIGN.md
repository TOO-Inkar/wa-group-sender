# Дизайн админки

Рабочий инструмент диспетчера, а не витрина: сначала понятность и скорость, бренд — в деталях. Цвета и шрифты
задаются только токенами из `src/styles/index.css`; в компонентах — классы Tailwind на этих токенах.

## Токены

| Роль | Светлая | Тёмная | Где |
| --- | --- | --- | --- |
| `bg` | `#f4f6f8` | `#101419` | фон страницы |
| `surface` / `surface-2` | `#ffffff` / `#f0f2f5` | `#1a2028` / `#222a34` | карточки, панели / наведение, активный пункт меню |
| `text` / `muted` | `#17202b` / `#64707f` | `#e7ebf0` / `#98a3b3` | основной текст / подписи |
| `border` | `#dfe4ea` | `#2d3642` | рамки и разделители 1px |
| `accent` | `#128c5e` | `#2fae7c` | главное действие, выбранное, прогресс, знак сервиса |
| `ok` / `warn` / `bad` / `info` | пары `*-bg` + `*-text` | | только статусы |
| `chat-bg` / `bubble` | | | предпросмотр сообщения WhatsApp |

Акцент — только на главном действии, выбранном и данных. Не красим им заголовки, рамки и украшения.

## Шрифт

Системный (`system-ui`, Segoe UI на Windows): один шрифт на всё, кириллица есть везде. Основной текст 15px,
подписи 13px, заголовок страницы 20px (`text-xl`), цифры — `tabular-nums`. Поля ввода на тач-экранах 16px
(правило в `index.css`), иначе iOS увеличивает страницу.

## Поверхности

- Карточки: `rounded-xl`, рамка 1px, **без тени**. Тень — только у того, что всплывает: модальные окна, шторки,
  меню, панель выбранных групп.
- Внутри карточки не делаем вторую карточку с рамкой — разделяем линией `border-t` или отступом.
- Цифры состояния — одной полосой (`StatsCards`), не плитками с иконками.
- Статусы — `Badge` с тоном из `shared/ui/tone.ts`.

## Сетка и адаптив

| Ширина | Навигация | Списки |
| --- | --- | --- |
| < 768px (`md`) | шапка сверху + нижняя панель разделов | заявки и группы — строки-карточки |
| 768–1023px | боковое меню 224px | заявки — строки-карточки |
| ≥ 1024px (`lg`) | боковое меню | заявки — таблица |

- Колонки сетки — `minmax(0,1fr)`, иначе широкая таблица раздувает страницу на телефоне.
- Таблицы шире экрана не делаем: на узких экранах — отдельная разметка списком.
- Всё фиксированное внизу (уведомления, панель выбранных групп) — выше нижней панели и
  `env(safe-area-inset-bottom)`.
- Проверка: страница на 390px не шире экрана (e2e `@phone`), скриншоты на 1440 / 768 / 390.

## Движение

Только состояние: 150–250 мс, `transition-colors` / ширина прогресса. Без анимаций появления страниц и секций.

## Знак

`shared/ui/logo.tsx` и `public/favicon.svg` — облачко чата, из которого сообщение расходится по трём группам.
Не заменять буквой в квадрате.

## Не делаем

Градиенты, эмодзи вместо иконок (иконки — только `lucide-react`), мелкие подписи капсом над заголовками,
стрелки «→» в конце кнопок и ссылок, тени на карточках в покое, одинаковые плитки с иконками в кружках.
