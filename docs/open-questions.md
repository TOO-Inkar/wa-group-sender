# Вопросы к запуску

Вопросы из раздела 8 ТЗ и решения по умолчанию. Текущее поведение — `README.md`.

## Решено

| Вопрос | Решение |
| --- | --- |
| Таблица клиента | Не нужна: заявки создаются в админке. Google Sheets оставлен выключенным (`SHEETS_ENABLED=false`), включение — README, раздел 12 |
| Боевой сервер | https://wa-group-sender.bid, раскладка `/home/ubuntu/wa-bot`, автодеплой из `main` после зелёного CI, ночной бэкап — README, раздел 6 |
| Работать ли в выходные, рабочее окно | Настройка в админке («Рассылать и в выходные», окно с/до), по умолчанию нет и 08:00–20:00. У заявки — «слать и вне рабочего окна» |
| Клиентский чат для алертов | Подписка через бота по ссылке из «Настройки» → «Уведомления в Telegram» с одобрением в кабинете; постоянные получатели — `TELEGRAM_CHAT_IDS` |
| Схема прогрева | 45 → 80 → 120 → 170 → 220 (`WARMUP_DAILY_LIMITS`), дальше — дневной лимит из админки; прогрев включается и выключается в админке |
| Контакт в сообщении | Поле «Контакт в конце» в каждой заявке, по умолчанию `MESSAGE_CONTACT` |
| Несколько номеров | Кабинеты: свой номер, группы, настройки и база; прокси на номер (README, раздел 5) |

## Решения, принятые по умолчанию, где ТЗ не уточняет

| Тема | Решение | Где меняется |
| --- | --- | --- |
| Данные заявки «Калжат → Баку» | В ТЗ нет её полного текста. В `docs/test-sheet.csv` заполнена правдоподобными значениями по образцу, эталон `golden/kalzhat-baku.txt` построен по ним | `docs/test-sheet.csv`, `src/test/resources/golden/kalzhat-baku.txt` |
| Нумерация при `MESSAGE_NUMBERING=true` | Keycap-цифры числового ID перед первой строкой: `1️⃣7️⃣ 📍*…*`. Для нечислового ID нумерация не ставится | `MESSAGE_NUMBERING` |
| Формат ID | Следующее число после максимального | — |
| Волны и паузы | Волна 25 групп, между волнами 10–20 мин, между группами 20–60 с (дробные секунды); пауза считается от начала предыдущей отправки. Индикатор «печатает…» не используется | админка, «Паузы» |
| Повтор в ту же группу | Тот же текст — не чаще раза в 45–60 мин (при интервале 60), только если после нашего сообщения кто-то написал | админка, «Каждая группа отдельно» |
| Пороги риска | Окно 1 ч, 5 сигналов → паузы ×2 и алерт, 10 сигналов → остановка и алерт | `RISK_*` |
| Что считается в лимиты | Каждая попытка отправки (успешная и неуспешная); лимит в час — за последние 60 минут | — |
| Отказ WhatsApp по группе | 2 повтора через 20–30 мин, не сигнал риска; после 3 итоговых отказов подряд группа исключается до «Сбросить» | — |
| Частичная неудача | Если хотя бы одна группа получила заявку — «Отправлено»; если ни одна — «Ошибка: не отправлено ни в одну группу» | — |
| Обрыв посреди отправки | Доставка в статусе SENDING после рестарта считается отправленной (дубль хуже пропуска), в логе `RECOVERED_AS_SENT` | — |
| Watchdog | 8 попыток переподключения, задержка от 10 с с ростом до 1 мин; после исчерпания — алерт и попытки раз в минуту | `WATCHDOG_*` |
